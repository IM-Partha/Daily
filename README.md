# 🎬 Dailymotion-style Video Web App

A responsive and user-friendly video streaming web application inspired by Dailymotion. Built using React.js and Firebase for authentication, it offers a seamless experience across devices.

---

## 🚀 Features

- 🔐 **User Authentication** (Login/Register) using Firebase
- 🔍 **Global Search Bar** using React Context API
- 🏠 **For You Page** with recommended videos
- 🌐 **Explore Page** to discover new content
- 📌 **Watchlist Page** to save favorite videos
- 📱 **Responsive Design** with a mobile-friendly navigation drawer
- 🔁 **Dynamic Navbar** based on user login state

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Authentication**: Firebase
- **Routing**: React Router
- **State Management**: React Context API
